# הרדאר שלנו 📡

אתר אירועים אישי בתל אביב, לשנינו ולנינה. מתעדכן לבד כל בוקר.

## מה יש כאן
- `index.html` – האתר עצמו.
- `data/events.json` – רשימת האירועים. מתעדכנת אוטומטית.
- `scraper/` – הסקריפט שאוסף אירועים מ־radartlv, בית רדיקל, קולנוע יפו, Secret Tel Aviv ואתר העירייה.
- `.github/workflows/update.yml` – האוטומציה שמריצה את הסקריפט כל בוקר ב־7:13.

## הקמה (פעם אחת, בערך 10 דקות)

1. **חשבון:** נכנסים ל־github.com ופותחים חשבון חינמי.
2. **מאגר חדש:** לוחצים על **+** למעלה ← **New repository**.
   - שם: `radar`
   - לבחור **Public** (רק כך האתר חינמי)
   - לסמן **Add a README file**
   - ללחוץ **Create repository**
3. **העלאת הקבצים:** במאגר לוחצים **Add file ← Upload files**.
   - גוררים פנימה את `index.html`, `package.json`, את התיקייה `data` ואת התיקייה `scraper`.
   - לוחצים **Commit changes**.
4. **קובץ האוטומציה:** התיקייה `.github` מוסתרת במחשב, ולכן יוצרים אותה ידנית.
   - לוחצים **Add file ← Create new file**.
   - בשם הקובץ כותבים בדיוק: `.github/workflows/update.yml`
   - מדביקים את התוכן של הקובץ `update.yml` מהחבילה.
   - לוחצים **Commit changes**.
5. **הרשאה לאוטומציה:** **Settings ← Actions ← General**. למטה, בקטע *Workflow permissions*, בוחרים **Read and write permissions** ושומרים.
6. **הפעלת האתר:** **Settings ← Pages**. תחת *Branch* בוחרים `main` ואת התיקייה `/ (root)`, ולוחצים **Save**.
   - אחרי דקה־שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/radar/`
7. **עדכון ראשון:** בלשונית **Actions** בוחרים "עדכון יומי של האירועים" ← **Run workflow**. מכאן והלאה העדכון רץ לבד כל בוקר.

## אם משהו לא עובד
- **ב־Actions מופיע ✗ אדום:** לוחצים על ההרצה ורואים את השגיאה.
- **אזהרה "נאספו רק X אירועים":** כנראה מבנה האתר של radartlv השתנה. במקרה כזה הנתונים הקיימים לא נמחקים.
- **בכל ריצה:** ב־`data/events.json` נשמר דוח (`report`) עם מספר האירועים שנאספו מכל מקור.
